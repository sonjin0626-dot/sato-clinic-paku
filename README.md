# 佐藤医院 Webリニューアル

EDIX フロント開発実習で制作する佐藤医院Webサイトです。

## 実装

- HTML / CSS / JavaScriptのみ。ビルド・外部スライダーライブラリ不要。
- Figma: https://www.figma.com/design/Hgvtb0tNAxk7go1yh3Cyzz/?node-id=72-697
- Desktop 1440px基準、コンテナ最大1200px。レスポンシブ対応は今回の対象外（最小幅1280px）。
- 画像19点はFigmaから取得し、assets/img/に保存。期限付きURLはサイトに使用していません。
- Google FontsのNoto Sans JP、Google Maps埋め込みにはインターネット接続が必要です。
- ギャラリーは6枚保持・3枚表示・1枚移動。Prev / Nextで操作し、両端で無効化。自動再生・ループ・アニメーションなし。
- JavaScriptが無効な場合も本文・表・ナビゲーションは利用可能。ギャラリーは横スクロールで閲覧できます。

## ファイル

- index.html: TOPページ、診療時間表2か所、アクセス、各案内
- css/style.css: 共通トークン、Desktopレイアウト
- js/main.js: ギャラリー、お知らせ案内ダイアログ
- assets/img/: ローカル画像19点
- assets/README.md: 画像とFigmaノードの対応
- .nojekyll: 静的ファイルをそのまま公開

## Figmaとの意図的な差分

- ルートpakuの黒枠を削除。ロゴをheader内に配置。
- セマンティックHTML、Grid / Flexbox、tableによって構造を整理。
- ギャラリーにPrev / Nextボタンと読み上げ用の表示状態を追加。
- MapFrame画像をGoogle Maps埋め込みへ変更。架空住所「東京都台東区上野 0-0-0」では正確な医院地点を指定できないため、上野駅周辺を表示し注記。
- 「その他の診療科目」はTOP内の診療科目へ、「より詳しく」は院長のご挨拶へ接続。独立した下層ページは未制作。
- お知らせは見出しのみ提供されているため、詳細・過去記事へのリンクで準備中の案内を表示。記事本文は創作していません。
- スタッフ山本花の経歴欄にあった「経歴：」の重複を修正。
- キーボードフォーカス、本文へのスキップリンク、画像alt、表の見出し・読み上げ情報を追加。

## GitHub Pages公開手順・公開前確認

1. このフォルダのファイルをGitHubリポジトリのmainブランチへコミット・push。
2. リポジトリのSettings → Pagesで「Deploy from a branch」、main / (root)を選択して保存。
3. 公開URLで画像・CSS・JavaScriptが読み込まれることを確認。全ローカル参照は相対パスで、プロジェクト配下のPages公開に対応。
4. 公開先でも1440pxでレイアウト、キーボード操作、Prev / Next、地図表示を確認。
5. 教材用ダミーの住所・電話・FAX・メール・医師経歴、お知らせ未提供、詳細ページ未制作を確認。電話・メールリンクもダミーなので、実医院として使う場合は実情報への差し替えが必要。
6. 画像の教材外公開に関する利用条件を確認。モバイル対応は別途実装。

GitHubへのpushとPagesの設定変更はこの実装作業では行っていません。
